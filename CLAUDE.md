# Project log

After every request that changes the project (or checks it), add an entry at
the top of the entries in `docs/CHANGELOG.md` and refresh its "Current status"
section: date, what was asked, what changed, migrations (and whether they are
applied to Neon), how it was tested, and anything still open. Keep earlier
entries; if a later request reverses something, say so in the new entry.
